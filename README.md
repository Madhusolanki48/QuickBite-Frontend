# QuickBite Frontend

This Angular app contains the customer workflow UI:

- sign-in with role selection
- login
- Google auth entry point
- restaurant browsing
- cart and mock payment flow
- orders, profile, and saved addresses
- local mock notifications and admin approval flows

## Run locally

```bash
npm install
npm start
```

This repository is frontend-only for now. API and payment gateway integration are intentionally stubbed out so you can connect the backend later without rewriting the UI.

## Asset folders

Drop images into:

- `public/assets/images/logo/`
- `public/assets/images/hero-banners/`
- `public/assets/images/categories/`
- `public/assets/images/food-items/`
